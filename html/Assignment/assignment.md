Assignment: Personal Portfolio Website
Objective
Build a multi-page personal portfolio website using only HTML, incorporating all concepts learned over the three-day course. This project will demonstrate your understanding of HTML structure, semantics, tables, forms, multimedia, and best practices.
Requirements
1. Structure

Pages: Create at least four pages:
Home
About
Projects
Contact


Use semantic HTML5 elements (<header>, <nav>, <main>, <section>, <article>, <aside>, <footer>) to structure each page.
Ensure each page includes a proper HTML boilerplate: <!DOCTYPE html>, <html>, <head>, and <body> tags.
Include a navigation menu on every page using <nav> and anchor tags (<a href>) linking all pages.

2. Content
Home Page

Headings and Paragraphs: Use <h1> to <h6> for a clear hierarchy and <p> for text content (e.g., a welcome message).
Text Formatting: Apply <strong>, <em>, <mark>, and other formatting tags to enhance text.
Images: Include at least one <img> with a proper alt attribute (e.g., a profile picture).
Links: Add anchor tags linking to the other three pages and one external link (e.g., a social media profile) with target="_blank" and rel="noopener".

About Page

Complex Table:
Create a table with at least 5 rows and 4 columns (e.g., education history or skills).
Include <caption> to describe the table (e.g., "My Education").
Use <thead>, <tbody>, and <tfoot> for structure.
Apply colspan and rowspan in at least two places to merge cells (e.g., spanning a "Total" row).
Style with inline CSS (e.g., style="border: 1px solid black; padding: 5px;") for borders and colors.


Lists: Use <ul>, <ol>, and <dl> to present additional information (e.g., hobbies, achievements, or definitions).
Iframe: Embed an <iframe> with a title attribute (e.g., a Google Map or YouTube video).

Projects Page

Form:
Create a <form> for submitting project ideas or feedback (no action or method needed since it’s HTML-only).
Use <fieldset> and <legend> to group related inputs (e.g., "Personal Info").
Include at least 5 different input types: email, tel, url, number, date, color, search, etc.
Add <textarea>, <select> with <option> for suggestions.
Implement validation attributes: required, pattern, min, max, step.
Use <label> for all inputs.


Multimedia:
Embed one <audio> and one <video> element.
Use <source> for multiple formats (e.g., MP3/WAV for audio, MP4/WebM for video).
Include <track> for captions/subtitles on the video.
Provide fallback text (e.g., "Your browser does not support this element").



Contact Page

Interactive Elements:
Use <progress> to show a task completion level (e.g., "Portfolio Progress: 80%").
Use the hidden attribute on an element (e.g., a secret message).


Form: Include a simple contact form with labeled inputs and validation.

3. Styling

Use the style attribute for inline CSS on all pages.
Style elements (e.g., tables, text, backgrounds) to enhance visual appeal.

4. Best Practices

Add comments in the HTML code to explain sections (e.g., <!-- Navigation Menu -->).
Ensure accessibility:
Use alt for images, title for links/iframes.


Validate your HTML using an online validator (e.g., W3C Markup Validator).
Design with responsiveness in mind (e.g., use percentage widths like style="width: 100%;.

5. Additional Elements

Global Attributes: Use id, class on various elements.
Head Section: Include in <head>:
<meta charset="UTF-8">


Time: Include a <time> tag (e.g., <time datetime="2023-10-15">October 15, 2023</time>).

Deliverables

A zipped folder containing:
All HTML files (e.g., index.html, about.html, projects.html, contact.html).
Assets (images, audio, video files).


A brief report (text file or HTML comment) explaining your choices and how each requirement was met.

Evaluation Criteria

Correct use of HTML elements and attributes.
Proper implementation of semantic HTML.
Functionality of forms, tables, and multimedia.
Visual appeal and user experience via inline styling.
Code cleanliness, including comments and validation.
Accessibility considerations.

Tips for Success

Plan the structure of each page before coding.
Use placeholder content (e.g., Lorem Ipsum) if needed, but keep it relevant.
Test your site in multiple browsers and screen sizes.
Refer to MDN documentation for tag/attribute details.
Focus on details in forms, tables, and multimedia for full marks.

This assignment ensures you apply all HTML concepts from the three-day plan while creating a functional and engaging portfolio website.
